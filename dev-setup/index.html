01

Install VS Code, Python, and uv on macOS, Windows, and Linux

Download sources, command-by-command setup, and verification
Setup
01Download VS Code only from code.visualstudio.com/Download.
02Download Python only from python.org/downloads or trusted package managers listed below.
03Install uv from docs.astral.sh/uv and use it as your default environment + package tool.
04Use one project folder per course project and always open that folder directly in VS Code.
05Run the verification checklist so you know the setup is fully correct before coding.
macOS full setup (recommended: Homebrew + zsh)
1) Download VS Code from the official site and drag it to Applications.
2) Open VS Code, press Cmd+Shift+P, run Shell Command: Install 'code' command in PATH.
3) Install Python with Homebrew:
brew install python@3.13
4) Install uv:
curl -LsSf https://astral.sh/uv/install.sh | sh
5) Reload terminal and verify:
python3 --version · uv --version · code --version
Windows full setup (recommended: winget + PowerShell)
1) Download VS Code from the official site or install with Winget:
winget install Microsoft.VisualStudioCode
2) Install Python 3.13 with Winget:
winget install Python.Python.3.13
3) During python.org installer flow, ensure Add python.exe to PATH is enabled.
4) Install uv in PowerShell:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
If blocked by policy, run once in PowerShell (as current user):
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Then re-run the uv install command.
5) Restart PowerShell and verify:
python --version · uv --version · code --version
Linux full setup (Ubuntu/Debian)
1) Install VS Code from Microsoft repo:
sudo apt update && sudo apt install wget gpg apt-transport-https
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" | sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null
sudo apt update && sudo apt install code
2) Install Python 3.13 and venv tools:
sudo apt install python3.13 python3.13-venv python3-pip
If python3.13 is unavailable on your distro, use one fallback path:
A) uv-managed Python:
uv python install 3.13
B) pyenv-based install:
curl https://pyenv.run | bash
pyenv install 3.13.2 && pyenv global 3.13.2
3) Install uv:
curl -LsSf https://astral.sh/uv/install.sh | sh
4) Restart shell and verify:
python3.13 --version · uv --version · code --version
Terminal navigation basics (all OS)
Use these commands every day to move inside project folders:
pwd (show current folder), ls (list files), cd folder-name (go into folder), cd .. (go up one level), mkdir project-name (create folder).
Windows PowerShell equivalents are the same for cd, ls, and mkdir.
Open current folder in VS Code with code ..

A fully verified local Python toolchain across macOS, Windows, or Linux, ready for the bridge course and AI engineering route.

03

Create your first project and environment step-by-step

From empty folder to running Python app in VS Code
Environments
01Create and open a folder: mkdir python-course-lab && cd python-course-lab, then code ..
02Open VS Code terminal and create environment with uv venv .venv.
03Activate environment:
macOS/Linux: source .venv/bin/activate
Windows PowerShell: .venv\Scripts\Activate.ps1
04Install starter tools: uv pip install ruff pytest then create main.py.
05Run Python: Select Interpreter and pick the interpreter inside .venv for this workspace.
first-run-checks.sh
# 1) show python path (must point to .venv)
which python

# 2) verify package install works
python -m pip --version

# 3) create and run a sample file
printf 'print("Python setup OK")\n' > main.py
python main.py

# 4) verify lint tool is available
ruff --version
first-run-checks.ps1
# 1) show python path (must point to .venv\Scripts\python.exe)
Get-Command python

# 2) verify package install works
python -m pip --version

# 3) create and run a sample file
Set-Content -Path main.py -Value 'print("Python setup OK")'
python main.py

# 4) verify lint tool is available
ruff --version

Editor settings and IntelliSense

The daily editing experience in VS Code
Editor
01Enable font, tab, wrap, and ruler defaults that fit Python code well.
02Turn on Pylance type checking and auto-import completions.
03Use inlay hints, sticky scroll, and bracket pair colorization for readability.
04Keep save-time actions focused: format, organize imports, and fix issues explicitly.
05Use the command palette for interpreter selection, sorting imports, and opening settings.
settings.json
{
  "python.defaultInterpreterPath": "${workspaceFolder}/.venv/bin/python",
  "python.terminal.activateEnvironment": true,
  "python.analysis.typeCheckingMode": "basic",
  "python.analysis.autoImportCompletions": true,
  "editor.stickyScroll.enabled": true,
  "editor.inlayHints.enabled": "on"
}
06

Linting and formatting

Ruff, Black, mypy, and flake8 as standalone tools
Quality
01Use Ruff for modern linting and formatting with a single config in pyproject.toml.
02Keep python.linting.* settings out of the project because they are deprecated.
03Install standalone tools like pylint, mypy, and flake8 only when the project needs them.
04Put formatter choice in the Python language block for consistent save behavior.
05Let the toolchain own import sorting, code actions, and line-length conventions.
07

Debugging with debugpy

Launch configs, breakpoints, and zero-config run
Debugger
01Use F5 to start debugging and Ctrl+F5 to run without debugging.
02Use debugpy in launch.json for modern Python debug configurations.
03Create launch entries for files, modules, web apps, pytest, and attach sessions.
04Use conditional breakpoints, logpoints, and hit counts when plain breakpoints are not enough.
05Use the call stack, watch expressions, and debug console to inspect runtime state.
launch.json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Run Current File",
      "type": "debugpy",
      "request": "launch",
      "program": "${file}",
      "console": "integratedTerminal"
    }
  ]
}

Common setup errors and quick fixes

Use this when setup commands fail or VS Code behaves unexpectedly
Troubleshooting
01code command not found: on macOS run Shell Command: Install 'code' command in PATH; restart terminal.
02Wrong Python used: run Python: Select Interpreter and pick the one inside .venv.
03.venv does not activate on PowerShell: use .venv\Scripts\Activate.ps1; if blocked, set execution policy for current user.
04Pylance or linting not active: confirm workspace is trusted and extensions are enabled in this workspace.
05Linux package not found for python3.13: use uv python install 3.13 or pyenv fallback path.
06PATH mismatch: restart terminal and run which python (or Get-Command python on Windows).
