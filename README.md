# Python Novice to Professional — Course Website

India's most comprehensive Python 3.13 course. Novice level to production-grade Python engineering in 8 weekends.

## Hosting on GitHub Pages

1. Create a new GitHub repository: `python-zero-to-pro`
2. Upload all files from this folder to the repo root
3. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Your site will be live at: `https://yourusername.github.io/python-zero-to-pro/`

## Files

## Customisation

- Change colours: edit `:root` variables in `styles.css`
- Add a new module: copy the `<div class="module" id="mXX">` block in `curriculum.html`
- Update pricing: edit the `.pricing-card` sections in `index.html`
- Change typewriter snippets: edit the `codeSnippets` array in `main.js`
